Telemetry Overlay - channel alias table
Extracted from the V8 constant pool of resources/app.asar -> main.jsc
(Telemetry Overlay build dated 2026-06-26)

A CSV column binds to a gauge when  "<header cell> (<units cell>)"  matches one of
these strings EXACTLY, including capitalisation and the degree sign. Note the table is
inconsistent by design - e.g. "Logger Temperature (°C)" needs the degree sign but
"Coolant Temperature (C)" does not. Always look up, never derive.

SPEEDUNITS / ALTITUDEUNITS are placeholders: any speed/altitude unit is accepted there.
